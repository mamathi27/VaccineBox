## 📖 Project Overview

**VaccineBox** is a web-based Vaccine Monitoring and Inventory Management System developed as a Smart India Hackathon (SIH) project.

The system helps healthcare organizations monitor vaccine storage conditions, maintain vaccine inventory, track expiry dates, and visualize important analytics through an interactive dashboard.

The goal is to reduce vaccine wastage, improve cold-chain monitoring, and assist healthcare workers in efficient vaccine management.

---

# 🎯 Problem Statement

Vaccines must be stored within a specific temperature range to remain effective.

Many healthcare centers still rely on manual record keeping, making it difficult to:

- Monitor storage temperature
- Detect cold-chain failures
- Track vaccine inventory
- Identify expiring vaccines
- Prevent stock shortages
- Generate analytical reports

A centralized digital platform is required to improve vaccine safety and operational efficiency.

---

# 💡 Solution

VaccineBox provides a centralized platform for:

- Cold-chain temperature monitoring
- Vaccine inventory management
- Expiry tracking
- Temperature breach detection
- Inventory analytics
- Real-time dashboard visualization

# 🚀 Installation

## Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/VaccineBox.git
```

---

## Go to Project Folder

```bash
cd VaccineBox
```

---

## Create Virtual Environment

```bash
python -m venv venv
```

---

## Activate Virtual Environment

### Windows

```bash
venv\Scripts\activate
```

### Linux / macOS

```bash
source venv/bin/activate
```

---

## Install Dependencies

```bash
pip install -r requirements.txt
```

---

## Run the Application

```bash
python app.py
```

---

Open Browser

```
http://127.0.0.1:5000
```
